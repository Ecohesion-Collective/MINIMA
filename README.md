# MINIMA: Minimal Nature-Integrated Macroeconomic Model

MINIMA is a stylized system-dynamics ecological macroeconomic model for illustrative and pedagogical purposes. It is introduced in Chapter 25 of the *Handbook of Ecological Macroeconomics*.

This repository holds the model file (`minima.mdl`), programmed in Vensim, and the output files (`.vdfx`) of the scenarios presented in the chapter. The full mathematical documentation of the model and a tutorial for using, exploring and modifying it in Vensim are available in the Appendices A and B of the Chapter.

## Overview

The model represents a hypothetical global economy with modules for production, aggregate demand and the labor market, which interact with the dynamics of energy, materials, the carbon cycle and climate change. Grounded in Post-Keynesian and Ecological Economics, it is designed to be a transparent, tractable and easily modifiable tool for students and researchers to learn and explore ecological macroeconomic modeling.

## Getting started

1. Install Vensim. A free version for academic use (Vensim PLE) is available at https://vensim.com/free-downloads/
2. Download the file **`minima.mdl`** from this repository.
3. Open it in Vensim and run the simulations (see Appendices A and B of the chapter for the documentation and a Vensim tutorial).
4. To explore the results of the chapter’s scenarios, download the `.vdfx` files, save them in the same folder as `minima.mdl`, and load them in Vensim as datasets.
